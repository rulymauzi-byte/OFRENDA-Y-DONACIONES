🔄 Sincronizar dispositivos

Los datos siempre quedan guardados en la memoria de este dispositivo y la app funciona sin internet. Con la sincronización activa, cada cambio llega por internet en segundos a los otros celulares o PCs que usen la misma clave, estén donde estén; si no hay señal, se envía solo al volver la conexión.

Paso 1 · Configuración de Firebase
  1. Entra a console.firebase.google.com y crea un proyecto (gratis).
  2. Authentication → Comenzar → activa el método Anónimo.
  3. Firestore Database → Crear base de datos → en Reglas pega las del archivo firestore.rules.
  4. Configuración del proyecto → Tus apps → Web (</>) → copia el bloque firebaseConfig y pégalo aquí.

Mínimo 6 caracteres. No importan mayúsculas ni tildes. Elige una que solo sepa tu equipo.

🌎 Agregar otro dispositivo (desde cualquier lugar)

Los datos viajan por internet: el otro celular o PC puede estar en otra casa, otra ciudad u otro país. Solo tiene que:

  1. Abrir la app en (o instalarla).
  2. Ir a Ajustes y escribir la clave del equipo:

…y tocar Conectar. En segundos le aparece toda la lista.

La invitación lleva un enlace que conecta solo al abrirlo. ⚠ Compártela solo con tu equipo: quien tenga la clave puede ver y editar la lista.

📲 Instalar la app

  • Android (Chrome): toca 📲 Instalar arriba, o menú ⋮ → Instalar aplicación.
  • iPhone (Safari): botón Compartir ⬆ → Agregar a pantalla de inicio.
  • PC (Chrome o Edge): ícono de instalar en la barra de direcciones, o menú → Instalar Ofrenda y Donaciones.

Para instalarla debe abrirse desde internet (por ejemplo GitHub Pages), no como archivo suelto.
